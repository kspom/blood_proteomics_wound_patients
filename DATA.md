# Data access

The input dataset (`dataset/` folder — Data.csv, ClassLabel.csv,
ProteinNames.txt, filtered_proteins.csv) is not included in this
repository because of data-sharing constraints of the study cohort.

To obtain the dataset for reproduction:
- Contact the corresponding author (see manuscript) for de-identified
  data-access requests.
- The expected `dataset/` layout is described in README.md.

The scripts assume `dataset/` sits at the repository root next to
`lib/`.
